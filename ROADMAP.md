# MediTrack - Roadmap (next semester ideas)
Already done: search, nearby pharmacies, price compare, availability, reserve, owner panel, login, categories,
favorites, alternatives, reviews, notifications + "notify me", admin panel, dark mode, reservation slip, emergency page.

Easy:
- Multi-language (Hindi / Marathi)  - Medicine reminder (email)  - Export reports (PDF/Excel) for owner/admin
- Charts on dashboards (Chart.js)   - Pagination + more filters (price range, brand)
Medium:
- Interactive map (Leaflet + OpenStreetMap) with pharmacy markers
- Cart: reserve many medicines in one go    - Prescription upload (image) + owner verification
- Medicine expiry tracking + low-stock auto alerts for owners   - Pharmacy opening hours / "Open now"
Advanced:
- Online payment (Razorpay/UPI test mode) + home delivery with order tracking
- AI chatbot for symptoms/medicine info     - OCR to read prescriptions   - REST API + mobile app (PWA)
- Deploy on Render/PythonAnywhere with PostgreSQL
